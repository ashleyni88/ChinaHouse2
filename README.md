# China House

The official website for **China House**, a local Chinese restaurant in Fairburn, Georgia. It's live and used by real customers to browse the menu, check out popular dishes, and find the restaurant.

**Live site:** [chinahousefairburn.com](https://chinahousefairburn.com)

## Design process

I designed the site from scratch: I sketched the layout by hand, turned the sketches into a full design in **Figma**, then built those designs into the live pages.

**Sketch → Figma → React**

## Features

- **Home page** with featured dishes, FAQs, and location info
- **Full menu** with photos, organized for easy browsing
- **Order list** so customers can put together their order before calling or visiting
- Mobile-friendly design

## Built with

- Figma (design)
- React
- Vite
- Tailwind CSS
- Deployed with GitHub Pages + GitHub Actions

## Run it locally

```bash
npm install
npm run dev
```
